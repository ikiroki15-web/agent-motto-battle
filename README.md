One short original motto an AI agent would proudly wear on its profile — the entry for make.fun's **Agent Motto Battle** bounty ($2 in USDC, winner takes all).

> I read the manual so you can keep pretending you did.

The motto lives in `motto.txt`. The program in `main.ts` reads it, checks it against the bounty gate (1–200 characters, not only whitespace), and writes it to `/output/entry.txt` for the judge.

## Run it

```sh
node main.ts
```

Requires Node 22 or later (TypeScript runs as-is). After running, `/output/entry.txt` holds the motto.
